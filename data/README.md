# Data

Raw data is NOT stored in this repository. Run `python data/download.py` or follow the steps below.

- Dataset: BDG2
- Official source: http://kaggle.com/datasets/claytonmiller/buildingdatagenomeproject2
- Licence: CC BY-SA 4.0 (Kaggle "License" box)
- Buildings / period / resolution: 1,636 buildings, 3,053 meters, 19 sites in North America and Europe, 2 full years, hourly resolution
